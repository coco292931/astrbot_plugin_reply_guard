# astrbot_plugin_reply_guard

群聊回复守卫。四件事：关键词精准回复、回复概率门、敏感词拦截、`/q` 引用图。

## 关键词精准回复

读一个 xlsx：

- A 列 = 关键词，B 列 = 回复内容
- 消息与关键词**完全一致**才触发（去掉首尾空白后比较）
- A 或 B 有一边为空的行直接跳过
- 同一个关键词出现多次，以**靠下**的那一行为准
- 命中后直接回 B 列内容，这条消息不进入 LLM、不写入历史

表格路径在配置里填，留空则读 `data/plugin_data/astrbot_plugin_reply_guard/keywords.xlsx`。
文件改完会按 `reload_interval` 秒自动重载，不用重启。

## 回复概率门

没命中关键词的消息，按全局概率决定是否交给 LLM 回复：

- 概率没过 → 不回复，消息也不写入历史
- 概率过了 → 正常走 LLM

默认只对群聊生效，私聊照常回复。可用 `mode` 改成私聊优先或全部生效。

## 敏感词拦截

LLM 生成完毕后检查回复正文（含消息链里的文本），命中任意一个敏感词就整条跳过，
不发消息，这轮消息也不写入历史。这是针对 LLM 回复的拦截，和上面关键词表没关系。

## /q 引用图

引用一条消息后发送 `/q`，按 qq-quote-generator 的样式渲染成引用图：

- 卡片 600 宽、圆角、浅色底，头像 40 圆形、昵称灰字、白色圆角气泡
- 正文 15px / 行高 24，消息里有图会贴在气泡里
- 被引用的消息递归画成嵌套引用（2px 竖条 + 8px 缩进），最多 3 层
- `/q N` 会带上被引用消息之后的 N-1 条群消息，最多 10 条
- 消息里有动态表情（QQ 表情动图 / GIF 表情）时输出动态 GIF，否则输出 PNG
- 渲染 2 倍输出，字体自动查找，也可以在配置里指定 `font_path`
- 图片和头像自己下载自己画，不需要额外的渲染服务

## 配置

面板里四组开关：关键词表、概率门、敏感词、引用图。范围（scope）留空表示全部会话，
可以填群号、用户号或完整会话标识（`平台:类型:ID`）。
